# Dollar a Day (D a D)

Dollar a Day is the first active public node operating through IPM.db.

Current functionality includes:

- public opt-in email workflow
- prewritten participation pledge
- e-transfer copy-to-clipboard system
- contribution pathway integration
- public accountability positioning

The initiative is structured around creating a stable micro-contribution funding stream intended to support housing and homelessness reduction.

Pilot focus remains Victoria, BC.
