# Graphics Inventory

Every page needs a graphic invitation.

Graphics are not decoration.

They are doors into reading.

## Required graphics

- `intro-egg`: >mi< egg in a working environment.
- `mi-dashboard`: personal >mi< dashboard inside the egg.
- `doer-energy`: action feeding the egg.
- `i2a-engine`: ideas moving into asset cards.
- `ipmdb-ledger`: living ledger and traceable record.
- `quality-a-plus`: A+ as the best current version.
- `quality-a-plus-plus`: A++ as the next improvement.
- `dad-flow`: contribution stream supporting launch.
- `ajf-parent`: AJF & Co. parent environment.

## Image rules

Use strong hero visuals.

Use fewer words inside images.

Keep logos locked and consistent.

Make every image invite the next click.

## Placeholder rule

If final art is missing, use a styled placeholder rather than leaving the page plain.
