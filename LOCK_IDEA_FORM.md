# Lock Idea Form

`lock-idea.html` is a field-driven intake form based on Issue #22: IPM.db LOCK YOUR IDEA.

Use it to:

1. Enter an idea.
2. Generate formatted GitHub issue text.
3. Copy the issue text.
4. Open a new GitHub issue.
5. Paste the prepared submission.

This first version is static. It does not require a backend.

Files:

- `lock-idea.html`
- `lock-idea.css`
- `lock-idea.js`
