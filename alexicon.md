# Alexicon

A working glossary for AJF&Co., IPM.db, Dollar a Day, Sandola, and related development language.

Alexicon records shorthand, acronyms, meanings, source notes, usage, and related IPM.db nodes.

External acronym sources such as Acronyms.com and Abbreviations.com may be used for reference lookup only. Alexicon entries remain curated, attributed, and context-specific.

## Entry Format

```text
TERM:
EXPANSION:
SOURCE:
CATEGORY:
AJF MEANING:
USAGE:
STATUS:
RELATED NODES:
DATE ADDED:
```

## Seed Entries

### gfn

**Expansion:** good for now

**Source:** AJF-defined

**Category:** Working shorthand

**AJF Meaning:** A version, phrase, build, image, or decision is acceptable for the moment and can be advanced without further refinement.

**Usage:** Marks completion of a working pass.

**Status:** Active

**Related Nodes:** Core System, IPM.db workflow

---

### 👍

**Expansion:** done / affirmative

**Source:** AJF-defined

**Category:** Signal shorthand

**AJF Meaning:** Confirms that a step is complete, correct, or approved.

**Usage:** One-click workflow confirmation.

**Status:** Active

**Related Nodes:** Core System, Workflow

---

### IPM.db

**Expansion:** Intellectual Property Management database

**Source:** AJF-defined

**Category:** Core system

**AJF Meaning:** A public and structured system for turning ideas into owned, trackable assets through attribution, contribution records, node development, agreements, and implementation.

**Usage:** Parent system for idea intake, public records, asset tracking, and node development.

**Status:** Active

**Related Nodes:** All nodes

---

### DAD

**Expansion:** Dollar a Day

**Source:** AJF-defined

**Category:** Funding node

**AJF Meaning:** A one-action contribution model proposing that $1/day from many people can create predictable funding streams for housing, support, and community outcomes.

**Usage:** Public-facing funding pilot and IPM.db node.

**Status:** Active

**Related Nodes:** Housing, Economic Development, Public Services

---

### PCWM

**Expansion:** Post-Consumer Waste Management

**Source:** AJF-defined / public usage context

**Category:** Node acronym

**AJF Meaning:** A node for waste, recovery, circular systems, local material handling, and post-consumer resource flow.

**Usage:** IPM.db development node.

**Status:** Active

**Related Nodes:** Public Services, Economic Development

---

### TDM

**Expansion:** Traffic Demand Management

**Source:** Public planning usage + AJF node usage

**Category:** Node acronym

**AJF Meaning:** A transportation node focused on mobility, access, trip reduction, demand-flow planning, and better use of existing movement systems.

**Usage:** IPM.db transportation node.

**Status:** Active

**Related Nodes:** Transportation, Governance, Public Services

---

### Sandola

**Expansion:** Sandola — Value in Motion

**Source:** AJF-defined

**Category:** Concept node / brand / settlement model

**AJF Meaning:** A draft IPM.db economic-development node for modelling secure, interoperable, and transparent value movement.

**Usage:** Visualizes contribution flow, public ledger movement, allocation movement, attribution-linked value events, and future settlement structures.

**Status:** Draft / Concept Node

**Related Nodes:** Economic Development, Dollar a Day, Public Ledger

---

### I2A

**Expansion:** Ideas to Assets

**Source:** AJF-defined

**Category:** Core phrase

**AJF Meaning:** The working transformation layer between raw ideas and owned, trackable assets.

**Usage:** IPM.db platform language and site framing.

**Status:** Active

**Related Nodes:** Core System

Record whether each entry is:

- AJF-defined
- public/common usage
- source-derived
- hybrid
