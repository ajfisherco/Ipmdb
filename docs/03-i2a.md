# I2A

## Core line

I2A is what IT does.

## Function

I2A means Ideas 2 Assets.

It takes raw ideas, claims, notes, choices, and contributions and moves them toward owned, trackable assets.

## Graphic invitation

A stream of sparks moving through a machine and exiting as asset cards.

Each card has an ID, title, originator, contributors, status, and version.
