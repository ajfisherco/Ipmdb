# IPMdb Launch Control

This file is the launch map for the Doer environment.

## Headline structure

> We are creating replicable working environments for anyone to use with >mi< to be tailored to personal use.
>
> “>mi<“ is the egg.
>
> “Doer” is the fertilizer.
>
> “I2A” is what IT does.
>
> Everything and everyone is behind IT.
>
> A+ = “THE BEST”
>
> A++ comes after that.

## Launch goal

Prepare IPMdb as a replicable working environment where a person can move from idea to asset through a clear, visual, guided path.

## Launch principles

1. Every page needs a graphic invitation.
2. Every page needs one clear action.
3. Every section must support >mi<, Doer, I2A, IPMdb, DAD, or Assets.
4. The public experience should feel like an exhibit, not a manual.
5. GitHub is the ledger, studio, and working archive.

## Launch stages

### Stage 1: Organize

Create the repository structure for vision, pages, graphics, deployment, and issue tracking.

### Stage 2: Build

Create the intro page, visual section pages, and deployment-ready static site files.

### Stage 3: Wire

Connect intake, email, DAD, ledger, and asset records.

### Stage 4: Test

Test desktop, iPhone, form submission, emails, links, QR, and payment routes.

### Stage 5: Launch

Publish the tested build to ajfisherco.com/ipmdb or the target standalone domain.

## DAD payment launch rule

Payments activate only after a contribution value is selected or entered.

Suggested options:

- $1/day
- $365/year
- Custom Amount

Remove the monthly option.

After amount selection, hide the option list and show:

- Contribution amount
- Days covered
- Next payment date

Active methods:

- Pay by Card
- E-Transfer
- QR Code

Remove the Complete button from the public payment flow.
