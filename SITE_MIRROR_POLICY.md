# AJF&Co. Site Mirror Policy

Status: GFN / working rule.

AJFisherCo.com is the build, test, whiteboard, and preparation space for public websites before each project separates into its own domain.

## Core rule

All future standalone sites should mirror the working site first built on AJFisherCo.com or its development subdomains.

AJF&Co. remains the parent-company development space.

Individual public domains may launch when ready, but the source structure, copy, design logic, and public flow should first be tested through AJF&Co.

## Current examples

- DAD / Dollar a Day is currently prepared and beta-tested through AJF&Co. and IPM.db infrastructure.
- DAD may later point to dad.org when secured.
- IPM.db remains the record layer.
- AJF&Co. remains the parent / build / implementation layer.

## Separation rule

A project may separate into its own domain only when:

1. The page flow works.
2. The public wording is clean.
3. The primary action works.
4. The parent-company link is present.
5. The public record / ledger path is clear.
6. Legal or status disclaimers are not misleading.
7. The project has a clear reason to stand alone.

## Parent-company mark

Use the locked AJF&Co. metallic emblem as a semi-discreet parent-company link on all related sites.

Placement:

- near the footer or lower continuity section
- visible but not dominant
- linked to https://ajfisherco.com

Purpose:

- parent-company approval
- continuity between projects
- quiet source attribution
- navigation back to the build layer

## Site mirroring pattern

For each new project:

1. Build the working page on AJF&Co. or an AJF&Co. subdomain.
2. Test the flow there.
3. Lock the accepted design/copy.
4. Mirror the site to the standalone domain when secured.
5. Keep AJF&Co. as the development and reference source.
