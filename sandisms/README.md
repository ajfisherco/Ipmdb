# Sandisms

Sandisms is a living phrase repository for AJF / Sand / IFN / Kekicon source wording.

This is not a cleanup desk.

This is a holding shelf for exact diction, coined terms, near-miss wording, autocorrect artifacts, meme-language, and project phrases that may later become posts, glossary entries, public copy, issue text, node language, or visual prompts.

## House rule

User wording is source text.

Do not normalize spelling, punctuation, capitalization, line breaks, or kektyle unless explicitly requested.

Separate:

- VERBATIM SOURCE
- SUGGESTED OPTION
- PUBLIC-FACING VERSION
