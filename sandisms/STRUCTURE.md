# Sandisms Structure

## Purpose

Sandisms preserves source wording, coined phrases, meme-language, typo-glyphs, autocorrect artifacts, IFN copy, COPO language, and public-facing phrase candidates.

## Folder plan

```text
sandisms/
  README.md
  STRUCTURE.md
  source/
    COVFEFE_KEKTYLE_AND_SANDISMS.md
  lexicon/
    terms.md
  posts/
    truth-social/
  images/
    prompts/
  issues/
    migration-to-own-repo.md
```

## Status states

- captured
- locked
- draft
- public-ready
- archived

## Handling rule

Do not edit source text silently.

When improving copy, preserve the source and place revisions under a separate heading.

## Example format

```md
## VERBATIM SOURCE

Exact user wording here.

## SUGGESTED OPTION

Only if requested.

## PUBLIC-FACING VERSION

Only if requested.
```
