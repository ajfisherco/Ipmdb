# Dollar a Day

## Asset ID

IPMDB-0002

## Purpose

To create a stable micro-contribution funding stream intended to help end homelessness and support housing outcomes.

## Current Status

Public prototype active.

## Operational Elements

- public opt-in email workflow
- contribution pledge system
- e-transfer integration
- public contribution tracking
- website participation flow

## Public Connector

AJFisherCo.com

## Contribution Flow

1. Visitor opts in
2. Visitor sends contribution
3. Participation is publicly tracked through IPM.db
4. Reporting and outcomes remain visible

## Pilot Focus

Victoria, BC

## Next Actions

1. Expand public participation
2. Formalize reporting structures
3. Develop charitable partnership pathways
4. Connect funding to measurable outcomes
