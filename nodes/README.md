# IPM.db Nodes

This directory contains the active nodes operating within IPM.db.

Each node represents a category, initiative, or operational branch with its own:

- contributors
- objectives
- agreements
- reporting
- assets
- implementation pathways

## Active Nodes

- Core System
- Dollar a Day
- Housing
- Transportation / TDM
- Governance
- Economic Development
- Public Services
- Post-Consumer Waste Management

Additional nodes are added as subject material and participation increase.
